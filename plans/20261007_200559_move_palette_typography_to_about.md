# Move palette and typography info from Appearance to About

**Status:** completed

## Issue

The Appearance screen (Settings → Appearance) has two sections, "Sacred Temple Palette"
and "Typography & Scripts". They only show information and do nothing when tapped. But
they use the same bordered cards and row layout as real settings, so users think they can
tap them to change colours or fonts. Information like this does not belong in Settings.

## Fix

1. **Appearance screen** — remove both sections. The screen keeps only the header card and
   the brightness setting.
2. **About screen** — add the same information as a plain, read-only "design" part, styled
   like the existing info rows (Purpose, Offline, Privacy, Backup):
   - Place it after the Backup info row, before the divider.
   - Heading row: palette icon + "Sacred Temple Palette" (reuse key
     `appearancePaletteSection`), in the same style as `_infoRow` titles.
   - Under it, one line per colour: a small colour dot (about 14 px, no shadow) + name in
     normal weight + role in grey. No cards, no borders, no dividers, so nothing looks
     tappable.
   - Heading row: font icon + "Typography & Scripts" (reuse key
     `appearanceTypographySection`).
   - Under it, one line per font: font name written in that font + use in grey. The
     bordered sample boxes are dropped, because they look like text fields.
3. **Appearance header subtitle** — the text now mentions palette and typography that are
   no longer on that screen. Change `appearanceHeaderSub` in all three languages to talk
   only about brightness and calm display:
   - en: "Set a calm screen brightness for distraction-free chanting."
   - ml: "ശ്രദ്ധ തെറ്റാതെ ജപിക്കാൻ ശാന്തമായ സ്ക്രീൻ തെളിച്ചം ക്രമീകരിക്കുക."
   - sa: "निर्विघ्नजपाय शान्तं पटलप्रकाशं योजयतु।"
4. No new ARB keys. All palette and typography keys are reused as they are. Run
   `flutter gen-l10n`.
5. **Tests**
   - `test/screens/appearance_screen_test.dart`: expect the palette and typography
     headings to be **absent**; brightness checks stay.
   - `test/screens/about_screen_test.dart`: add checks that the palette and typography
     headings and one colour name appear.
6. Run `dart format .`, `flutter analyze`, `flutter test`.

## Notes

- `TempleColors` and `AppTheme` font helpers will be imported into the About screen from

  not app details, so it does not go in `AppConfig`.

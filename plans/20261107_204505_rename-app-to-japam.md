# Rename the app to "Japam"

**Status:** completed

## Issue

The app's display name is "SreerajP MantraJapa Counter". It is too long for the phone's
launcher, which cuts it off to something like "SreerajP Man…". The user wants:

- **On the phone (launcher + About screen):** "Japam" (English), "ജപം" (Malayalam),
  "जपम्" (Sanskrit).
- **On the Play Store:** "Japam – Mantra Japa Counter". This is set in Play Console, not in code
  (see "Manual steps" below).

The package id (`com.sreerajp.mantrajapacounter` and `.dev`) does **not** change. Changing it would
make Google Play treat it as a new app, and current users would never get updates.

## Steps

1. Edit files 1–11 and 13–22 as listed.
2. Run `flutter gen-l10n`.
3. Run `dart format .`, `flutter analyze`, `flutter test`.
4. User builds and installs the dev flavor (`flutter run --flavor dev`) and checks the launcher
   name in English, Malayalam and Sanskrit, and the About screen.
5. Write the change log.

## Manual steps for the user (not code)

- Play Console → Grow → Store presence → Main store listing → **App name**:
  `Japam – Mantra Japa Counter` (27 of 30 characters). Add Malayalam/Sanskrit listings if wanted.
- Before publishing, search the Play Store for "Japam" to see if other apps use the same name.
- If the privacy policy is hosted online, update the hosted copy too.

## Security impact

None. Only display text in the platform resource files changes. No permission, manifest
attribute, package id, signing or storage change. Backup format is not touched, so old backups
still import.

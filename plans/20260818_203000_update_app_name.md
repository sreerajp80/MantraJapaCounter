# Implementation Plan — Update App Name to SreerajP MantraJapa Counter

**Status:** Completed
**Date:** 2026-08-18

---

## 1. Goal

Update the application name throughout the codebase, build configuration, localization resources, and tests to **"SreerajP MantraJapa Counter"** (prod) and **"SreerajP MantraJapa Counter Dev"** (dev).

---

## 2. Motivation / Problem Statement

The user requested that the app name be changed to **SreerajP MantraJapa Counter**. While `assets/config/app_config.json` already contains this new name, several files in the code, build configuration, fallback configs, test assertions, and localization files still use "Mantra Japa Counter".

---

## 3. Files to Modify

1. `android/app/build.gradle.kts`
   - Update product flavor `app_name` string resources:
     - `dev`: `"SreerajP MantraJapa Counter Dev"`
     - `prod`: `"SreerajP MantraJapa Counter"`

2. `lib/config/flavor_config.dart`
   - Update `AppFlavorConfig.appName` return values:
     - dev: `'SreerajP MantraJapa Counter Dev'`
     - prod: `'SreerajP MantraJapa Counter'`

3. `lib/core/config/app_config.dart`
   - Update fallback config `AppConfig.fallback.appName` to `'SreerajP MantraJapa Counter'`.

4. `lib/l10n/app_en.arb`
   - Update `"appTitle"` to `"SreerajP MantraJapa Counter"`.
   - Update `"backupShareSubject"` to `"SreerajP MantraJapa Counter Backup"`.

5. `pubspec.yaml`
   - Update `description` to `SreerajP MantraJapa Counter — track your mantra recitation practice.`.

6. `test/core/config/config_service_test.dart`
   - Update fallback assertion to expect `'SreerajP MantraJapa Counter'`.

7. `AGENTS.md` and `CLAUDE.md`
   - Update the identity tables and flavor tables to reflect `SreerajP MantraJapa Counter` / `SreerajP MantraJapa Counter Dev`.

# Plan: Re-format code for the Dart 3.13.5 formatter

**Status:** completed

## The issue

After moving to Flutter 3.47.6 (Dart 3.13.5), the check
`dart format --output=none --set-exit-if-changed .` fails. It says 26 of 142 files
would be re-formatted. The most likely reason is that the new formatter version lays out
some code a little differently (line breaks, indentation, trailing commas).

This is a style-only issue. No app behavior is wrong.

## The fix

1. Run `dart format .` from the project root. No hand edits.
2. Check that the changes are whitespace/layout only:
   - Run `git diff --stat` to confirm only the 26 files above changed.
   - Compare each file before and after with all whitespace removed. If the only
     differences are whitespace and trailing commas, the change is layout only.
   - Read through the diff by eye as a final check.
3. Run `dart format --output=none --set-exit-if-changed .` again. It must report
   0 changed files.
4. Run `flutter analyze`. It must be clean (0 issues).
5. Run `flutter test` on Windows, golden tests included. All tests must pass.
   - Golden tests compare screenshots. Formatting does not change widget output, so no
     golden images should need updating. If a golden test fails, stop and report it —
     do not re-generate golden images as part of this change.
6. Write a change log in `change_log/` and set this plan to `completed`.

# Keep the earlier-day banner after 108 until the user leaves

**Status:** completed

Follows: `plans/20261007_201744_keep_unfinished_mala_banner.md` (completed).

## Issue

After the last change, the banner hides as soon as the mala reaches 108. But the session is
still the one that started on an earlier day. The user can keep counting into that old
session with no warning and no **Start new** button in view.

Also, after 108 the text "Unfinished mala from an earlier day: N/108" is no longer true.
N would be the count of the new mala.

## Wanted behaviour (confirmed by the user)

- Once the banner shows on a visit, it stays until the user leaves the screen, even after
  the mala reaches 108. Tapping **Start new** or **Finish & start new** still hides it.
- Before 108 it shows the current text: "Unfinished mala from an earlier day: N/108".
- After 108 it shows new text: "This session started on an earlier day", with the same
  **Start new** button.
- On the next visit, the banner shows only if the mala in progress still holds earlier-day
  taps (no change from the last plan). So after finishing that mala, leaving and coming
  back, it does not show.

## Plan for the fix

1. **`counting_provider.dart`**
   - Add a field `earlierDayMalaFinished` (bool, default `false`) to `CountingState` and
     `copyWith`. It is true when the banner is shown but the earlier-day mala is already
     done.
   - In `tap()` and `decrement()`: keep the banner on for the rest of the visit:
     `resumedFromEarlierDay = state.resumedFromEarlierDay || _holdsEarlierDayTaps(updated)`,
     and `earlierDayMalaFinished = resumedFromEarlierDay && !_holdsEarlierDayTaps(updated)`.
   - `init()` and `finishAndStartNew()` stay as they are (the flag starts fresh on each
     visit and is cleared by Start new).
   - Update the doc comments.
2. **`counting_screen.dart`** — pass `earlierDayMalaFinished` to `_UnfinishedMalaBanner`.
   When true, show the new text; otherwise show the current N/108 text.
3. **ARB files** — add key `earlierDaySessionBanner` with an `@` description:
   - en: "This session started on an earlier day"
   - ml: "ഈ സെഷൻ മുൻ ദിവസം തുടങ്ങിയതാണ്"
   - sa: "इदं सत्रं पूर्वदिने आरब्धम्"
   Then run `flutter gen-l10n`.
4. **Tests** (`counting_provider_test.dart`):
   - "today's taps go into a new row dated today": the banner stays on at 108, and
     `earlierDayMalaFinished` turns true at 108.
   - "banner is gone after the mala is finished and reopened": during the visit the banner
     is still on after 108; after reopening it is off.
   - "Start new" test: also check `earlierDayMalaFinished` is false.
5. **`docs/architecture.md`** — update the banner line to match.
6. Run `dart format .`, `flutter analyze`, `flutter test`.
7. Write the change log in `change_log/`.

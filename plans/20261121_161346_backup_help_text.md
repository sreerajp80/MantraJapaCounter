# Plan: Update backup help text for settings and running counts

**Status:** completed

## The issue

Backups now also hold the app settings and each counter's unfinished mala (see
`plans/20261121_155352_backup_settings_and_running_count.md`). The Backup &
Restore help screen still says only counters, goals and session history go into
the file, and that import replaces only counters and history. This is now wrong
in all three languages.

## Files to change

| File | Change |
|------|--------|
| `lib/l10n/app_en.arb` | New text for `helpBackupExportBullet1` and `helpBackupImportBullet2`. |
| `lib/l10n/app_ml.arb` | Same two keys, Malayalam. |
| `lib/l10n/app_sa.arb` | Same two keys, Sanskrit. |
| `lib/l10n/app_localizations*.dart` | Regenerated by `flutter gen-l10n` (not edited by hand). |

Only the values change. No key is added, renamed or removed, so key parity and
the `@key` descriptions stay as they are. No Dart code changes.

## The fix (new text)

### `helpBackupExportBullet1`

- **en:** All counters, goals, session history, app settings and the unfinished
  mala of each counter go into one backup file. Custom notification sounds stay
  on this phone.
- **ml:** എല്ലാ കൗണ്ടറുകളും ലക്ഷ്യങ്ങളും സെഷൻ ചരിത്രവും ആപ്പ് ക്രമീകരണങ്ങളും
  ഓരോ കൗണ്ടറിലെയും പൂർത്തിയാകാത്ത മാലയും ഒരു ബാക്കപ്പ് ഫയലിൽ. സ്വന്തം അറിയിപ്പ്
  ശബ്ദങ്ങൾ ഈ ഫോണിൽ മാത്രം നിൽക്കും.
- **sa:** सर्वे गणकाः, लक्ष्याणि, सत्रेतिहासः, संयोजनानि, प्रतिगणकम् असमाप्ता
  माला च एकस्यां प्रतिलिपिसञ्चिकायाम्। स्वकीयाः सूचनाध्वनयः अस्याम् एव
  दूरवाण्यां तिष्ठन्ति।

### `helpBackupImportBullet2`

- **en:** Import replaces ALL current counters, history, settings and unfinished
  malas with the data in the file. Export first if you want to keep what is on
  the phone.
- **ml:** ഇംപോർട്ട് ഇപ്പോഴത്തെ എല്ലാ കൗണ്ടറുകളും ചരിത്രവും ക്രമീകരണങ്ങളും
  പൂർത്തിയാകാത്ത മാലകളും ഫയലിലെ ഡാറ്റ കൊണ്ട് മാറ്റും. ഫോണിലുള്ളത്
  സൂക്ഷിക്കണമെങ്കിൽ ആദ്യം എക്സ്പോർട്ട് ചെയ്യുക.
- **sa:** आयातः वर्तमानान् सर्वान् गणकान्, इतिहासं, संयोजनानि, असमाप्ताः मालाः
  च सञ्चिकादत्तांशेन प्रतिस्थापयति। दूरवाण्यां स्थितं रक्षितुम् इच्छति चेत्
  प्रथमं निर्यातं करोतु।

The Malayalam and Sanskrit lines reuse words the ARB files already use
(ക്രമീകരണങ്ങൾ / संयोजनानि for "settings", മാല / माला for "mala"). They should be
read by a native reader before release.

The Optical Sync help is not changed: a selected QR import keeps the phone's
settings, and the help there does not claim otherwise.

## Steps

1. Edit the two values in each of the three ARB files.
2. Run `flutter gen-l10n`.
3. Run `dart format .`, `flutter analyze`, `flutter test` (includes the
   translation parity test).
4. Write the change log.

## Security impact

None. Text only; no code, storage, permission or network change.

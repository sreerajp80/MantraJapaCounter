# Update old import/export texts for settings and unfinished malas

**Status:** completed

## What the issue is

Since `change_log/20261121_160535_backup_settings_and_running_count.md`, every backup also holds
the app settings and each counter's unfinished mala, and a full import replaces them. The help
screen was updated (`change_log/20261121_161731_backup_help_text.md`), but two other texts still
describe the old backup:

| Key | Where it shows | Old English text (problem) |
|-----|----------------|----------------------------|
| `importExportBody` | Import / Export dialog (`lib/screens/counter_list/import_export_dialog.dart`) | "Export backs up all counters and sessions…" (no settings, no unfinished malas) |
| `tutorialStep25Desc` | App tutorial step 25 (`lib/screens/help/tutorial_help_screen.dart`) | "All counters and history are saved to one file…" |

Checked and left as they are (still true):
- Import warnings ("Import replaces ALL current data…", `tutorialStep26Tip`, `helpFaqQ10Answer`):
  "all data" already covers settings.
- `helpFaqQ10Answer` says Optical Sync only adds or updates the chosen counters. Still true:
  the QR import sheet always imports selected counters (the button is off when none are
  picked), and a selected import never changes settings.

## Files to change

| File | Change |
|------|--------|
| `lib/l10n/app_en.arb` | New values for `importExportBody`, `tutorialStep25Desc` |

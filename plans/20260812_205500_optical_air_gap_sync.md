# Implementation Plan — Optical Air-Gap Sync (High-Density Animated QR Stream)

**Status:** Proposed

## Overview

**Optical Air-Gap Sync** enables 100% offline, serverless, device-to-device synchronization of mantra counters, active sitting progress, and practice history between nearby mobile devices using screen-to-camera optical QR code streams (10–15 FPS).

### Why Optical Air-Gap Sync for Mantra Japa Counter?
1. **100% Offline & Zero Network Isolation**: Does not use Wi-Fi, Bluetooth, NFC, local sockets, or cloud services, preserving the app's core mandate: **Zero INTERNET permission, zero telemetry**.
2. **High-Density Data Transfer**: Exporting full practice histories with hundreds of session records exceeds single static QR code capacity (limited to ~2 KB). The Animated QR Stream splits the JSON backup into fixed-size chunks, encodes them with Luby Transform (LT) Fountain Codes and CRC32 checksums, and streams them continuously.
3. **Robust Loss-Tolerant Scanning**: Camera frame drops do not block decoding. Parity frames generated by Fountain Code decoding allow out-of-order reconstruction so the receiving device can recover missing chunks automatically.

## User Review Required

- **Dependencies to Add:**
  - `qr_flutter: ^4.1.0` (for rendering QR codes on screen)
  - `mobile_scanner: ^7.1.2` (for live camera QR frame scanning)

  Neither package requires internet or external network access. Camera permission (`android.permission.CAMERA`) is required **only** on the receiving device when scanning.

- **Data Format Compatibility:**
  The Optical Sync payload uses the exact same byte-compatible JSON structure as the existing JSON File Export (`JsonImportExportService`), wrapped in Luby Transform (`AIRQR|LT1`) chunking headers.

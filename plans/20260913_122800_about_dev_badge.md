# Implementation Plan — Use Visual Badge for Dev Flavor on About Screen

**Status:** completed
**Date:** 2026-09-13
**Slug:** about-dev-badge

---

## 1. Summary of the Issue

On the About screen (`lib/screens/about_screen.dart`), the app title currently appends the string `' Dev'` directly to the localized app name when running in the dev flavor:
- In Sanskrit: `मन्त्रजपगणकः Dev`
- In Malayalam: `മന്ത്ര ജപ കൗണ്ടർ Dev`
- In English: `SreerajP MantraJapa Counter Dev`

Appending an English word `' Dev'` directly to non-English localized titles looks inconsistent. The user requested replacing this text suffix with a clean visual chip/badge.

---

## 2. Proposed Solution

1. **Update `_resolveAppName` in `lib/screens/about_screen.dart`**:
   - Return the clean localized title `l.appTitle` without appending `' Dev'`.
2. **Add a visual badge in `lib/screens/about_screen.dart`**:
   - In the header of the About screen, display the app title alongside a styled `DEV` badge when `AppFlavorConfig.isDev` is true.
   - Use a `Wrap` widget to keep the layout responsive and centered.
   - Style the badge using a pill container matching the temple theme (`primaryContainer` with subtle outline and `onPrimaryContainer` text).
3. **Allow testing flavor in `lib/core/flavor/flavor_config.dart`**:
   - Add `@visibleForTesting static void setFlavorForTesting(AppFlavor flavor)` so tests can test both dev and prod rendering.
4. **Update tests**:
   - Ensure `test/screens/about_screen_test.dart` passes and add test coverage verifying that the dev badge renders when running dev flavor, and does not render in prod flavor.

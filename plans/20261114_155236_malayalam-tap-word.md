# Plan: One Malayalam word for "tap" — തട്ടുക / തട്ടൽ

**Status:** completed

## The issue

The Malayalam text uses several words for "tap": തൊടുക, തൊടൽ, തൊടലുകൾ, ടാപ്പ് (English
loan word), and സ്പർശനം / സ്പർശിക്കുക. The user wants one word everywhere in the app:

- tap (verb) → **തട്ടുക**
- tapping / a tap (noun) → **തട്ടൽ**

The user chose to change the whole Malayalam app, not only the new Meru pause strings.

## Files to change

| File | Change |
|------|--------|
| `lib/l10n/app_ml.arb` | about 63 strings reworded (list below) |
| `lib/l10n/app_localizations_ml.dart` | regenerated by `flutter gen-l10n` |

English and Sanskrit do not change. No Dart code changes. Key names do not change, so the
key parity test still holds.

The change covers every place where the text means "tap": counting taps, tapping buttons,
icons and cards, and tap-to-focus on the camera.

**Not changed:** `featCat4Name` and `featImmersionH2` use സ്പർശന പ്രതികരണം for *haptic
(vibration) feedback*, which is not a tap. They keep their wording.

## Steps

1. Edit each string in `app_ml.arb` by hand (not a blind find-and-replace, because the word
   endings and the grammar around them change).
2. Run `flutter gen-l10n`.
3. Check that no തൊട / ടാപ്പ് words are left (apart from the haptic ones above).
4. `dart format .`, `flutter analyze`, `flutter test`.
5. Write the change log.

## Security impact

None. Text only.

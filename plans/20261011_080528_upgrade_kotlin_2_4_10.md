# Upgrade Kotlin to 2.4.10

**Status:** completed

## Issue

The Android build uses the Kotlin Gradle Plugin 2.4.0. The user wants to move to Kotlin 2.4.10
(a bug-fix release in the same 2.4 line).

## Files to change

- `android/settings.gradle.kts` — change the `org.jetbrains.kotlin.android` plugin version
  from `2.4.0` to `2.4.10`.
- `CLAUDE.md` — update the "Android toolchain" row in the Project identity table to say
  Kotlin 2.4.10.

## Files NOT changed (on purpose)

- `docs/guidelines/flutter_build_flavors_guide.md` and
  `docs/guidelines/flutter_project_engineering_standard.md` — these are shared guideline
  snapshots of what a fresh Flutter 3.47 project generates. They are not this project's
  settings, so they stay as they are.
- Old plans and change logs — they are history.

## Plan

1. Edit the Kotlin plugin version in `android/settings.gradle.kts`.
2. Edit the toolchain row in `CLAUDE.md`.
3. Keep `android.builtInKotlin=false` as is.
4. Verify:
   - `flutter analyze` (must be clean).
   - `flutter test`.
   - `flutter build apk --flavor dev --debug` to confirm Gradle resolves Kotlin 2.4.10 and
     the Android build still works.
5. Write a change log in `change_log/`.

## Risk

Low. A patch release in the same minor line. If the build fails, revert the one-line
version change.

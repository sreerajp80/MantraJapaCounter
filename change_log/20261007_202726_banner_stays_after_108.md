# Keep the earlier-day banner after 108 until the user leaves

Implements plan: `plans/20261007_202547_banner_stays_after_108.md`
(follows `plans/20261007_201744_keep_unfinished_mala_banner.md`).

## What changed

### `lib/providers/counting_provider.dart`
- New `CountingState.earlierDayMalaFinished` field (also in `copyWith`). It is true when the
  banner is shown but the earlier-day mala is already done.
- New `_withBannerFor(session)` helper, used by `tap()` and `decrement()`. Once the banner is on,
  it stays on for the rest of the visit. `earlierDayMalaFinished` turns on when the mala that
  held earlier-day taps is finished.
- When undo takes the count back to 0 and a fresh session starts, both flags are cleared.
- `init()` and `finishAndStartNew()` are unchanged: each visit starts fresh, and Start new
  clears the banner.
- Updated doc comments.

### `lib/screens/counting_screen.dart`
- `_UnfinishedMalaBanner` gets a `malaFinished` flag. When true it shows the new text
  "This session started on an earlier day"; otherwise the existing "N/108" text.

### Localization
- New key `earlierDaySessionBanner` in `app_en.arb` (with `@` description), `app_ml.arb` and
  `app_sa.arb`. Regenerated the `app_localizations*.dart` files with `flutter gen-l10n`.

### `test/providers/counting_provider_test.dart`
- The banner stays on through 108; `earlierDayMalaFinished` turns true at 108.
- During the visit the banner is still on after 108; after reopening it is off.
- Start new also clears `earlierDayMalaFinished`.

### `docs/architecture.md`
- Updated the banner description.

# Change log — Flutter 3.50.1 and Kotlin 2.4.20

Implements plan: [plans/20261127_045718_flutter_3_50_kotlin_2_4_20.md](../plans/20261127_045718_flutter_3_50_kotlin_2_4_20.md)

## What changed

| File | Change |
|------|--------|
| `android/settings.gradle.kts` | Kotlin Gradle plugin `2.4.10` → `2.4.20` |
| `android/app/build.gradle.kts` | Comment now says "matches the Flutter 3.50 app template" (the 3.50 template still lets the Flutter plugin apply Kotlin, so nothing else changed) |
| `.github/workflows/ci.yml` | `flutter-version: 3.47.6` → `3.50.1` |
| `CLAUDE.md`, `AGENTS.md` | Flutter 3.50.1, "Dart 3.14.0 ships with Flutter 3.50.1", Kotlin 2.4.20 |
| `README.md` | Prerequisites: Flutter 3.50.1 or higher |
| `docs/implementation_progress.md` | Flutter SDK 3.50.1+ / Dart 3.14.0+ |

AGP 9.4.1 and Gradle 9.8.0 were already in place — no change.

Not changed (as planned): `pubspec.yaml` `sdk: ^3.13.5` (already allows Dart 3.14.0),
`material_ui` / `cupertino_ui`, and the read-only `docs/guidelines/` submodule.

## Checks

- `flutter pub get` — `pubspec.lock` did not change from the SDK upgrade alone.
- `dart format --set-exit-if-changed .` — 0 files changed.
- `flutter analyze` — no issues.
- `flutter test` — all 481 tests passed.
- `flutter build apk --flavor dev --debug` — built in about 4 minutes, no warnings. The
  Flutter migrator did not change any Android file. (This build also included the package
  upgrade from [change_log/20261127_113319_pub_package_upgrade.md](20261127_113319_pub_package_upgrade.md).)
- Installed on a real phone (Android 10, API 29 — the app's minSdk, 32-bit ARM). The app starts
  and shows the home screen. No Flutter or Android runtime errors in logcat.
- Permissions on the installed dev APK: no new ones. `INTERNET` appears only because the
  `debug` manifest adds it for hot reload; the `main` manifest removes it with
  `tools:node="remove"`, so release builds stay offline.
- Gradle daemons stopped after the build; no `GradleDaemon` or `KotlinCompileDaemon` left.

## Not verified yet

- Manual feature checks on the phone: Optical Sync receive (camera), file picking, daily
  reminder notification.
- A prod release build.

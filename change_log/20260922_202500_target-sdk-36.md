# Change log: Raise targetSdk from 35 to 36

**Plan:** [plans/20260922_201837_target-sdk-36.md](../plans/20260922_201837_target-sdk-36.md)

## Why

Google Play Console rejected version code 29. Play now requires apps to target
API level 36 (Android 16).

## What changed

| File | Change |
|------|--------|
| `android/app/build.gradle.kts` | `targetSdk = 35` → `targetSdk = 36` |
| `pubspec.yaml` | Version `6.12.1+29` → `6.12.2+30` |
| `lib/core/utils/app_version.g.dart` | Regenerated with `dart run tool/generate_app_version.dart` → `6.12.2+30` |
| `assets/config/app_config.json` | About screen version `6.12.1` → `6.12.2` |
| `CLAUDE.md`, `AGENTS.md` | Identity table: `targetSdk 36` |
| `README.md` | "compile/target SDK 36"; release commands use `android-prod-v6.12.2` symbols folder |
| `docs/features.md` | "Target SDK 36 (Android 16)" |

`compileSdk` did not change. It already comes from Flutter (`flutter.compileSdkVersion` = 36).

## Additions to the plan

The plan did not list `app_version.g.dart`, `app_config.json`, or the version in the
README release commands. They were updated so every copy of the version matches
`pubspec.yaml`.

## Verification

- `flutter analyze` — no issues.
- `flutter test` — all 160 tests pass.

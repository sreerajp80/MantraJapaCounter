# Upgrade Kotlin to 2.4.10

Implements plan: `plans/20261011_080528_upgrade_kotlin_2_4_10.md`

## What changed

- `android/settings.gradle.kts` — the `org.jetbrains.kotlin.android` plugin version changed
  from `2.4.0` to `2.4.10`.
- `CLAUDE.md` — the "Android toolchain" row now says Kotlin 2.4.10.

`android.builtInKotlin=false` is unchanged. The shared guideline snapshots in
`docs/guidelines/` were left as they are on purpose (they describe what a new Flutter
project generates, not this project's settings).

## Verification

- `flutter analyze` — no issues found.
- `flutter test` — all 313 tests passed.
- `flutter build apk --flavor dev --debug` — built successfully. (The first try failed with a
  Dart VM out-of-memory error because it ran at the same time as the tests. Running it again
  on its own worked. This was not related to Kotlin.)

# Raise compileSdk to 37 (keep targetSdk 36)

Implements plan: `plans/20261011_123556_compile_sdk_37.md`

## Why

After `flutter pub upgrade`, the prod release build failed at `:app:checkProdReleaseAarMetadata`.
`flutter_local_notifications` (23.0.0-dev.3) and `androidx.core` / `androidx.core-ktx` 1.19.0 need
the app to compile against Android API 37. The app was using `flutter.compileSdkVersion`, which is 36.

## What changed

- `android/app/build.gradle.kts` — `compileSdk = flutter.compileSdkVersion` is now `compileSdk = 37`,
  with a comment that says why, that `targetSdk` stays 36 on purpose, and to switch back once
  Flutter defaults to 37 or higher.
- `README.md` — toolchain row now says "compile SDK 37, target SDK 36, min SDK 29".
- `CLAUDE.md`, `AGENTS.md` — Platform(s) row now also lists `compileSdk 37`.

Not changed: `targetSdk` (still 36), `minSdk` (still 29), Dart code, manifest, tests.

## Checks

- `flutter analyze` — no issues.
- `flutter test` — all 313 tests passed.
- `flutter build apk --flavor prod --release` — build succeeded; the AAR metadata check passes.

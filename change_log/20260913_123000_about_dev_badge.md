# Change Log — Use Visual Badge for Dev Flavor on About Screen

**Date:** 2026-09-13
**Plan:** `plans/20260913_122800_about_dev_badge.md`
**Author:** Antigravity

---

## 1. What Changed

1. **`lib/screens/about_screen.dart`**:
   - Updated `_resolveAppName()` to return the clean localized app title without appending the text string `' Dev'`.
   - Updated the About screen header so the app title sits inside a `Wrap` widget alongside a styled `DEV` badge container when running in the dev flavor (`AppFlavorConfig.isDev`).
   - Styled the badge with `primaryContainer` background, a subtle border, and `onPrimaryContainer` bold text matching the temple theme palette.

2. **`lib/core/flavor/flavor_config.dart`**:
   - Added `@visibleForTesting static void setFlavorForTesting(AppFlavor flavor)` to enable switching flavors cleanly in unit and widget tests.

3. **`test/screens/about_screen_test.dart`**:
   - Added widget tests verifying that the `DEV` badge appears when running in the dev flavor.
   - Added widget tests verifying that the `DEV` badge is not displayed when running in the production flavor.

---

## 2. Rationale

Previously, the app title appended `' Dev'` directly to localized titles, creating mixed English and Indic titles such as `मन्त्रजपगणकः Dev` or `മന്ത്ര ജപ കൗണ്ടർ Dev`. Using a visual badge cleanly identifies the development build while keeping the title text localized and pure.
